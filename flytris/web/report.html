UNDER THE SHELL

What actually learns?

Board features enter a fixed fly-derived spiking circuit. Eight learned output weights choose a placement from its activity.

The fly animation illustrates recorded decisions. It is not a biomechanical simulation. Removing recurrent connections did not consistently hurt performance in these trials, so fly wiring has not been shown to be essential.
